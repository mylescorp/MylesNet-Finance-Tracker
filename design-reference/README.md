# MylesNet Finance Tracker: redesign package

- `AGENT_PROMPT.md`: the full implementation brief to give to the agent.
- `previews/`: PNG renders of all 18 boards (fonts fall back to a system font here).
- `boards/`: the same 18 boards as standalone HTML (open in a browser; images load from `../assets`).
- `canvas-source/`: the original design-canvas files and `canvas.json` (board positions).
- `design-tokens/`: tokens.css, tokens.json, tokens.ts, tailwind preset (colour, type, spacing source of truth).
- `assets/`: logo.png and banner.png.
- `references/`: screenshots of the original Google Sheet and the templates.
